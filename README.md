# COBB CAN MOVE

This directory contains the static export files for the COBB CAN MOVE deployment.
This README is regenerated after each build so it is not lost.

## About

COBB CAN MOVE is a fan-developed survival horror browser game built around changing rules.
You move through a dark top-down space, finish small tasks, and adapt as each round teaches a new way Cobb can find, chase, or pressure you.
The tension comes from how sound, sight, smell, and distance keep changing what counts as a safe route.
